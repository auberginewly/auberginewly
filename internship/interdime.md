# Interdime｜Photon Web & iOS

**北京维度之间科技有限公司｜全栈开发实习生｜2026.05 -- 2026.08**

## Photon Web｜创作者工作台

**项目简介：** Photon 面向空间视频创作者提供的 Web 工作台，服务内容经营与商业化运营场景。

**我的职责：** 负责上述核心业务的前端迭代，并参与数据分析相关的后端统计链路建设。

- **推广投放与支付回流：** 负责 Promotions 多步骤创建与管理流程，覆盖目标选择、视频选择、投放详情、预算设置与支付结账；根据订阅、审核与推广状态组织步骤流转，并处理支付回流、草稿恢复和异常重试，避免外部结账中断导致的配置丢失或重复创建。基于 Canvas 生成 1920×1080 PNG 创意预览，封装跨域图片代理降级、加载超时、输入防抖及 Blob URL 回收；列表页按推广及审核状态收敛编辑、暂停、恢复与删除权限。

- **创作者数据看板：** 针对创作者长周期查看内容数据时直接聚合原始行为记录开销较高的问题，负责前端 Analytics 页面及后端统计链路建设；前端基于 Recharts 封装趋势图表，扩展 Y 轴 nice-step 刻度、X 轴标签采样、Tooltip 与日期格式化，并结合 SWR + Zustand 持久化查询视图状态。后端基于 Go + PostgreSQL 构建日级摘要表、索引与历史回填机制，配合 Redis 读穿缓存；在 10,000 内容 / 90 天基准下，摘要查询约 9.2 ms，缓存路径 p95 为 0.662 ms。

- **SEO 与首屏媒体优化：** 针对 Vite + React SPA 首屏内容难以被稳定抓取、媒体资源影响首屏加载的问题，设计 SEO fallback 预渲染与构建校验链路，落地 metadata、canonical、Open Graph、JSON-LD、sitemap 与 robots.txt，并修复 fallback 可见时的闪屏。通过 IntersectionObserver、poster 与 preload 优化首页视频加载，将两段首屏视频资源体积合计减少 77.7%；Search Console 7 天点击量由 464 增至 516（+11.2%），CTR 由 16.4% 提升至 19.2%，平均排名由 5.18 提升至 4.44。

- **创作者激励与认证：** 负责 Incentives 模块迭代，打通激励计划加入、收益看板、周奖励结算与 Creative Partner 认证流程；基于 SWR 获取收益与资格状态，并通过统一 Dialog 状态管理组织机构加入、收益记录、提现方式与认证申请等交互，减少多入口弹窗之间的状态耦合。

## Photon iOS｜空间视频分享客户端

**项目简介：** Photon 是面向空间视频创作与分享的产品，iOS 客户端聚焦移动端内容消费与创作场景。

**我的职责：** 独立完成 Photon iOS 2.0 核心页面重构，围绕空间视频内容发现、独立沉浸式播放、个人主页及发布链路优化移动端体验。

- **发现与沉浸式播放链路重构：** 针对旧 Home 卡片内播放受列表复用、滚动和导航生命周期影响的问题，重构为“双列瀑布流发现 + 独立播放页”；以播放器协调器统一管理当前/下一条预加载、缓冲失败、循环播放及资源释放，并将横竖屏、返回、评论等关键交互抽离为可测试状态，基于 Swift Testing 建立播放与导航场景的回归保障。

- **个人主页与空间视频适配：** 针对普通视频、旋转视频与 SBS 空间视频混排时画幅不一致的问题，重构作品卡、待发布卡与社交列表；抽取视频比例解析服务，按旋转信息修正显示尺寸并以单眼宽度适配 SBS 内容，利用 actor 缓存和同 URL 并发请求合并减少重复媒体解析，统一发现页与个人主页的作品流布局。

- **发布与账号会话隔离：** 针对上传状态分散及账号切换可能遗留任务、缓存的问题，将发布流程建模为队列化任务，支持进度展示、取消、失败重试及发布后内容刷新；同步完善 Keychain 凭证恢复、账号级缓存失效和关联任务清理，避免旧会话异步结果回写到新账号。
